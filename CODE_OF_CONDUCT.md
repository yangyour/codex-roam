# Code of Conduct

## Our Standard

We expect respectful, technical, and inclusive collaboration. Feedback should
address the work, not the person. Harassment, discrimination, intimidation,
sexualized behavior, doxxing, and deliberate exposure of credentials are not
acceptable.

## Enforcement

Report unacceptable behavior privately to the repository owner through the
contact method listed in the GitHub profile. Include links or a factual summary
and avoid posting private credentials in the report.

Maintainers may remove content, close discussions, or restrict participation
when necessary to protect the community.
